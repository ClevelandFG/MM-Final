# 上下文说明

本文档用于记录Agent与用户达成的共识、约定俗成的术语等内容。

---

## 术语表

- **道路网络**：由题面给出的无向加权图构成，节点表示乡镇、村或辅助道路点，边权表示对应路段的千米数。
- **县政府所在地**：节点 `O`，所有巡视路线均从该节点出发并最终返回该节点。
- **乡（镇）节点**：`A`–`R` 中除 `O` 外的大写字母表示的必须巡视节点；在计时问题中每个乡（镇）停留时间记为 `T`。
- **村节点**：数字 `1`–`35` 表示的必须巡视节点；在计时问题中每个村停留时间记为 `t`。
- **辅助道路节点**：`U01`–`U05`，为保留题面道路权重而人工添加，只作为路径连接点，不计入必须巡视点，也不产生停留时间。
- **巡视路线**：一组巡视人员从 `O` 出发，访问分配给该组的必须巡视节点，并返回 `O` 的闭合路线。
- **路线组**：同一方案中若干条巡视路线的集合；组数即同时派出的巡视队数量。
- **路线方案**：由一条或多条巡视路线组成的完整候选方案，用于回答固定组数、最少组数或最短完成时间等问题。
- **总路程**：一个路线组内所有巡视路线行驶里程之和。
- **完成时间**：一个路线组内耗时最长路线的总耗时；单条路线总耗时由行驶时间与节点停留时间共同决定。
- **均衡性**：多条巡视路线在选定“工作负载”上的接近程度。工作负载可以是路线距离、总耗时、服务节点数或服务量；本项目第 (1) 问优先按路线距离理解均衡，第 (2)–(4) 问优先按总耗时和瓶颈路线理解均衡。
- **参数敏感性**：固定或改变组数时，乡镇停留时间 `T`、村停留时间 `t`、车速 `v` 的变化对最佳路线结构与目标值的影响。
